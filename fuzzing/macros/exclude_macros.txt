# NDEBUG is deliberately NOT excluded.
#
# Production defines it, and the fuzz build keeps it, so assert() stays compiled
# out. That matters for exactly one assert: Absolution's generated fuzzer ends
# every iteration with `assert(check_invariant() == 0)`, which re-verifies that
# the sampled globals still satisfy the invariant model *after* the app has run.
#
# That check suits an entrypoint which does not modify the modelled state. These
# harnesses are the opposite case -- restoring state and then letting the app
# mutate it is the point -- so the assertion fires within a couple of iterations.
#
# Do not remove NDEBUG here to re-enable the assertion: CMake's RelWithDebInfo
# flags put -DNDEBUG straight back. Narrow the model to globals the entrypoint
# must not touch instead; it is not a build-flag change.
